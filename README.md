Flight ticket search application with a focus on UI/UX design and flight search logic.

This project presents a flight search interface and demonstrates a structured approach to handling travel search flows and data presentation.

- Booking flow UI
- API integration structure
- Frontend interaction logic

## Purpose

- UI/UX design exploration
- Travel search system implementation
